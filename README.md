# RoanokeMowers.com

Dealer website for **Roanoke Golf Cars, LLC** focused on the full Bad Boy line: mowers, tractors,
implements, UTVs, light construction equipment and outdoor power tools.

- **Demo it:** [docs/DEMO.md](docs/DEMO.md) (GitHub Codespaces, no installs needed)
- **Deploy it:** [docs/DEPLOY.md](docs/DEPLOY.md) (Cloudflare Workers checklist)
- **Project status and decisions:** [docs/PROJECT_NOTES.md](docs/PROJECT_NOTES.md)

## Stack

| Layer | Choice |
| --- | --- |
| Framework | Next.js 16 (App Router, React 19, TypeScript) |
| CMS / admin | Payload 3 (runs inside the Next.js app at `/admin`) |
| Hosting | Cloudflare Workers via the OpenNext adapter |
| Database | Cloudflare D1 (SQLite), schema managed by Payload migrations |
| Files | Cloudflare R2 |
| Styling | Tailwind CSS 4, Archivo variable font (self-hosted) |
| Tests | Vitest (access rules, data integrity) and Playwright (pages, admin) |
| CI | GitHub Actions on every push and pull request |

## Local development

Requires Node 22.23+ or 24.22+ and pnpm 10.

```bash
bash .devcontainer/setup.sh   # install, create local DB, load catalog
pnpm dev                      # http://localhost:3000  (admin at /admin)
```

Local Cloudflare bindings (D1, R2) are simulated by Wrangler in `.wrangler/`. Delete that folder
and re-run the setup script to start over.

| Command | What it does |
| --- | --- |
| `pnpm dev` | Run the site locally |
| `pnpm seed` | Load or refresh dealership info and the Bad Boy catalog (safe to re-run) |
| `pnpm payload migrate:create <name>` | Create a migration after changing a collection |
| `pnpm payload migrate` | Apply migrations to the local database |
| `pnpm generate:types` | Regenerate Payload and Cloudflare types |
| `pnpm typecheck` / `pnpm lint` | Static checks |
| `pnpm test:int` / `pnpm test:e2e` | Tests |
| `pnpm build` | Production Next.js build |
| `pnpm preview` | Build and run the real Worker locally |
| `pnpm deploy` | Migrate the remote database and deploy (needs Cloudflare credentials) |

## Project layout

```
src/
  access/        Staff roles and reusable access rules
  collections/   Payload collections (Models, Categories, Media, Users)
  globals/       Site-wide settings (dealership info)
  fields/        Shared field definitions
  seed/          Catalog data (data/catalog.json) and seed script
  migrations/    Database migrations (commit these)
  lib/           Data access and formatting helpers
  components/    UI components
  app/(frontend) Public website
  app/(payload)  Admin panel and API (generated by Payload, don't edit)
tests/
  int/           Vitest
  e2e/           Playwright
```
